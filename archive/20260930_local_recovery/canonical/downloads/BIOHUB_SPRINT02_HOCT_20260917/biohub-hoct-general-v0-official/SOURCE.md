# HOCT official public inference asset

This dataset repackages only public MIT-licensed HOCT inference code and the
official `general_v0.pt` checkpoint so that internet-disabled Kaggle notebooks
can reproduce inference.

- Upstream repository: https://github.com/royerlab/hoct
- Upstream commit: `cabe8fd43b21653b8d717ac7758c07fd1f7c13cb`
- Paper: https://arxiv.org/abs/2607.11754
- Checkpoint SHA-256: `024c2e4606275c96667907abfc9e0c27487b543480caf99d9ebd1d267cef8e4a`
- Source license: MIT, retained in `LICENSE`

No competition labels, private data, or locally trained weights are included.
