# Cell tracking during development — inference notebook

This notebook loads two pre-trained detection models and a transformer edge model, runs them over each test movie, and writes `submission.csv`.

**Pipeline**

1. **Detection** — a dual-seed `TemporalUNet3D` predicts per-frame cell-center heatmaps; the two seeds are fused (secondary weight `0.80`) and peaks become candidate nodes.
2. **Edge scoring** — a `SimpleNodeTransformer` scores every plausible parent to child link between consecutive frames.
3. **Track selection** — an integer-linear-program (ILP) picks a globally consistent set of edges, allowing appearances, disappearances, gap closures and divisions.
4. **Division post-processing** — a `safe-div` rule proposes divisions the ILP missed, a `DeepCenter` model vetoes false positives, and a **sister-symmetry gate** rejects divisions whose two daughters are implausibly asymmetric.

Every setting is passed through `BIOHUB_*` environment variables in the first code cell, which is annotated block-by-block. The configuration guard cell then asserts the critical values before inference begins.

---

**This run — `biohub-div45-stack`: division-geometry double-loosening.**

Two independent safe-div distance caps are widened together. Each is already worth **+0.001** on the leaderboard on its own (0.938 -> 0.939), and both are grounded in a ground-truth measurement of real division geometry (`sister_sep_probe.py`), which showed the previous caps were slicing off genuine divisions:

- `BIOHUB_SAFE_DIV_SISTER_MAX_UM` 12 -> **14 um** (daughter-to-daughter). GT sister separations reach 13.7 um (median 10.4, p90 13.0); the 12 um cap rejected ~29% of real divisions. Alone: `sismax14` = LB 0.939.
- `BIOHUB_SAFE_DIV_MAX_UM` 7 -> **9 um** (parent-to-daughter). GT parent-daughter links reach 10.4 um; the 7 um cap rejected ~25% of real links. Alone: `safedivmax9` = LB 0.939.

Both loosenings recover *wide-but-genuine* divisions while the sister-symmetry gate (tau=0.6), mutual-NN, divergence and DeepCenter vetoes keep suppressing spurious wide pairs. This kernel tests whether the two +0.001 effects **stack** (target 0.940). This is a standalone notebook -- it is not forked from any other kernel.

---

**This run stacks a THIRD division lever on the combo base: the forward-divergence precision gate.**

Base = `sismax14-sdm9` (SISTER_MAX 14um + SAFE_DIV_MAX 9um, both LB 0.939 alone; DeepCenter = best.pt/epoch-2). On top of the two cap-*loosenings* (which admit more wide-but-genuine divisions), this run *tightens* the forward-divergence test:

- `BIOHUB_SAFE_DIV_DIVERGE_UM` 2.25 (silent default) -> **4.5um**. A proposed division is accepted only if, one frame later, its two grandchildren have moved apart by MORE than this margin beyond the current sister gap (`grandchild_dist - sister_dist >= DIVERGE_UM`). Larger = stricter = rejects spurious forks that don't actually separate over time. This is an *orthogonal* precision signal to the tau=0.6 sister-symmetry gate (divergence-over-time vs instantaneous symmetry).

Mechanism: loosened caps admit more real wide divisions into the pool; the stricter divergence test filters the spurious ones the looser caps let in ("admit more, filter harder"). An independent LB sweep of this exact parameter (public fork) showed a smooth unimodal optimum near 4.0-4.5 worth roughly +0.015 over the 2.25 default on a lower base. We expect a smaller, base-discounted gain here since our symmetry gate already removes some false forks. This is a standalone notebook -- it is not forked from any other kernel.
