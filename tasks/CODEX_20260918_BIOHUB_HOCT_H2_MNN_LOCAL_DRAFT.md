## 2. 唯一研发假设：互为最近邻的普通连接不删

候选名：`H2_MNN_KEEP`。保留G1＋HOCT流程，只收紧H1的普通边删除集合。

对于G1的普通连接u(t)→v(t+1)，在完整G1最终节点快照上检查：v是否为u在下一帧唯一的最近邻，同时u是否为v在上一帧唯一的最近邻。两者都成立，就保护该连接，即使HOCT没有选择它也不删除。无法可靠判定时也保留原边。

形式化定义：设D1为原H1依据可靠覆盖、完整求解和原guard得到的待删普通边。令M(e)取MUTUAL、NOT_MUTUAL或UNKNOWN，则：

```text
D2 = { e in D1 : M(e) == NOT_MUTUAL }
E_H2 = E_G1 minus D2
```

H2只少删一些原边，不加G1原本没有的边，不删节点，不改坐标，不改受保护分裂出边。也可从H1恢复D1减D2，但必须恢复G1原边属性与顺序。

选择该假设的理由是现有缓存已含最终节点和H1结果，可用CPU检查，无需新模型、重新推断或调数值阈值。几何互近邻不是独立于G1的新模型信号，也不保证正确；密集细胞、定位误差及G1后处理坐标可能使其失效。尚无证据证明三条已知正确边满足该条件，更不能预填“恢复3/3”或“保留12条FP删除”。本草案提出的是一次可证伪的小型实验，不是已找到提分方案。

## 5. 实现规则必须与标注隔离

1. 推理接口只接收G1预测图、H1删除集合／可靠覆盖证据、静态单位元数据。不得接收真实标注、TP/FP归属、三边编号清单或oracle恢复结果。视野名称只可用于日志，不可用于决策分支。
2. 最近邻搜索必须覆盖对应帧的全部G1最终节点，不能只在被删边端点或有标注节点里搜索。用固定完整节点快照计算，不能边恢复边改变候选集合。
3. 使用物理空间距离。先从G1生成源码和元数据确认坐标是否已经是微米；若已转换，不再乘尺度。若为体素，按原元数据转换。不能猜单位或为当前三条边选择距离度量；无法确认单位则停止并报告。
4. 仅处理t→t+1普通边。非相邻帧、缺少端点、非有限坐标、最近距离并列、映射无法确认，判UNKNOWN并保留。精确最近邻采用float64；不加从标签调出的容差或距离阈值。近邻查询需识别并列，不用编号大小打破平局。
5. 候选图节点编号只用于连接关系。对节点做一致的随机重编号、行顺序重排，恢复原编号后D2必须相同。不得硬编码三条边、帧7/77/85、胚胎或视野名称。
6. 所有440条D1边使用完全相同规则；不只给已知TP运行保护。报告保护了多少TP、FP、UNKNOWN时，必须在删除集合冻结之后，由独立评价步骤读取归属。
7. MNN函数不能读真实标注文件。先保存规则代码、输入清单、D2及其哈希，再执行评价。隐藏／删除标注目录时，相同预测输入仍须生成相同D2。事后冻结不能把本面板变成未见验证集；三条TP早已被分析这一限制必须保留。
8. 只实现这个候选，不追加高置信阈值、长窗口、分裂筛选、再链接或坐标校正。失败后不按三条TP反复调规则，也不自动改为提交原H1。
