## 2. 任务与总体设计思路

比赛目标是从 3D+time 显微影像建立细胞谱系图：每帧检测细胞中心，建立跨帧连接，并识别一个母细胞到两个子细胞的分裂。历史官方研究记录的指标为 adjusted_edge_jaccard + 0.1 × division_jaccard。评分补丁与重算曾发生，历史 Notebook 卡片 Best Score 不等于某个当前版本的有效提交分数。

工程主线是“节点检测 → 物理距离候选 → 时序/分裂边评分 → 图优化 → 后处理 → 合法 CSV”。优化始终需要区分检测召回、关联正确性、分裂拓扑和节点数量项，不能把某个局部 proxy 的上升自动解释为正式榜分上升。

### 最后生产链的结构

1. 主检测模型与 TemporalUNet3D/辅助关联模型形成候选和边特征；DeepCenter 作为安全分裂信息来源。不是本轮从零训练的新模型。
2. 保留已有融合/TTA、权重、head、时序方向与物理单位；通过模型文件哈希、CUDA 日志、实际挂载版本和运行回执绑定部署身份。
3. ILP 全局关联求解；division weight 影响分裂项。正式调用链从环境变量进入常量、CLI 参数、cfg，再到 ILPSolver，不能只在 metadata 中改数字。
4. readmit 从低阈检测缓存向开放轨迹端点前后各一帧补回候选，半径 4 μm，并执行同帧已有节点排重。低阈缓存补丁必须先于 head 加载/替换。
5. motion relink 区分有 flow 和无 flow 两条路径。FLOW_RELAXED_UM=0 使用原继承公式，不等于物理阈值为 0；末期实验实际普通输出中 flow 消费 792 次、no-flow 0 次，后者的逻辑另有合成测试，不能声称普通数据覆盖了两条分支。
6. 最终坐标使用 `max(0, int(round(float(node[axis]))))`，不提前整数化内部坐标。完整 CSV 检查样本覆盖、字段、整数坐标、连续 ID、唯一节点/边、合法端点、时间前进和入出度。

## 4. 有效经验、失败经验与限制

- **MEASURED：Public 的最高显示值从早期 .939 到 .958；团队最终 Private .919。** 这是不同阶段/方案的观测轨迹，不是控制全部条件后的统一增益分解。
- **MEASURED：最后五份没有新增 Public 提升。** Private 出分后，降低 ILP 分裂权重到 .4 并配 readmit .94 的公开优势未转化为更高 Private。不能事后断言 .6 或 1.2 是总体最优。
- **SOURCE_CODE_VERIFIED：参数必须沿真实消费链验证。** 环境变量、生成 support 文件、CLI、求解器和 runtime counters 要闭合。只改配置名、只看源码 hash 或普通 SUCCESS 都不足以证明隐藏评分正确。
- **MEASURED：可见 CSV 相同不代表隐藏预测相同。** XR0迁移中的可见输出与正式分数已经出现不一致的比较现象，不能以此猜测平台故障。
- **SOURCE_CODE_VERIFIED：训练样本重叠与胚胎分组限制必须保留。** 199 个视野不等于199个独立胚胎；TRAIN_SEEN_DIAGNOSTIC 不升级为无泄漏CV；部分差异诊断因缓存缺口保持 UNKNOWN。
- **MEASURED：SDK timedelta 序列化曾丢失 days。** GPU UI 30小时与 to_dict 的6小时不一致；后来用 `.total_seconds()` 得到108000秒，保留原始异常，不追认旧批即时额度检查缺口。
- **SOURCE_CODE_VERIFIED：响应不明先只读对账。** 账本先计数，绑定 owner/slug、Version、SV、submission 与源码；不通过重试、改名或额度重置规避预算。
- **INFERENCE：更稳健的未来研究应事先冻结独立验证、实验预算与最终选择原则。** 本次不补跑，不使用已见 Private 进行新的模型选择实验；无 Private 胚胎分项，机制结论仍有限。
