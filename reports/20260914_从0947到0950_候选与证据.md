**为什么选这个改动。** 0.947 母版的普通运行实际选择 `tight55`，只覆盖 `MOTION_RELINK_TIGHT_UM=5.5`；其旧 proxy 从 `0.9490371529912655` 升到 `0.9510944139858309`，正式 Public 却是 `0.947`。两个值来自不同数据和评分路径，不能直接把差额归因于某一个错误。但在实际执行的同图合成反例中，旧 proxy 与官方分裂匹配的确会不同：`weak_component_same_branch` 的旧 proxy division Jaccard 是 1.0，官方是 0.0；`one_pred_fork_two_gt_divisions` 旧 proxy 计 TP=2，官方 TP=1、FN=1。这证明现有选参信号存在不等价情况，尚不证明真实八个验证 FOV 的排序必然改变。

当前普通日志有 122,808 个节点、118,548 条边、124 个分裂状父节点；四个视频的分裂数分别为 55/25/10/34，均与 safe-div 新增数相同。旧 proxy 在选中配置上报告分裂 TP/FP/FN=3/1/9；这仍是旧 proxy 的计数，未按官方评分器重新计算，不能称为正式错误分解。原始 motion relink 记录替换 118,389 条原边，表示重建边容器的数量，不能解释成这些端点全部发生改变。以上均为 `MEASURED` 普通运行事实，不是隐藏评分产物。
